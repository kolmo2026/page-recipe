ローカルPDFをページレシピで編成

PDFを選ぶと、このブラウザー内で処理します。元ファイルは変更せず、新しいファイルをダウンロードします。

普通の暗号化されていないPDF向けです。電子署名、フォーム、しおりなどの保持は保証しません。

    例：A:5-3,A:1,A:1 は5、4、3、1、1ページです。内部エラーの文面は英語です。

    paper.pdf (5 pages) · supplement.pdf (2 pages)
