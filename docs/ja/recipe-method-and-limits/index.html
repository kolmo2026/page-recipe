ページ編成レシピが残すもの、残さないもの

kolmo2026 · 運営について

公開 2026-11-03 · 更新 2026-11-04

ページレシピは組立ての指示であり、保管庫ではありません。どの元資料の物理的な何ページを、どの順にコピーするか記録します。再構成には同じローカルPDFと、それを利用する権限が必要です。

記法の全体

A:1         1ページだけ
A:1-3       両端を含む昇順：1, 2, 3
A:5-3       両端を含む降順：5, 4, 3
A:1,A:1     意図的なページ重複
A:2,B:1     二つの元資料から選択

別名は大文字の英字で、ファイル選択時に割り当てます。区切りの前後の空白は使用できます。項目はカンマで区切ります。0ページ、範囲外、未登録の別名、空の項目があると出力を止めます。レシピ上の上限は10,000ページですが、それだけの大きなPDFをブラウザーのメモリーで扱える保証ではありません。

メタデータの一致は同一性の保証ではない

JSONにはバージョン1、レシピ、別名、元ファイル名、ページ数を保存します。再読込時は名前とページ数が一致する必要があります。ただし別のPDFでも同じ名前とページ数になり得るため、ファイル内容の同一性は確認できません。版と見える内容を確認してください。PDF自体は含まれませんが、ファイル名が見えるので共有前に点検します。

ページコピーは編集より狭い処理

pdf-libで選択ページを新しいPDFにコピーします。入力のバイト列は変更しません。ブラウザーには新しいダウンロードを渡します。手動保存時も元資料と同名のファイルを上書きしないでください。

文書単位のしおり、添付、フォーム動作、ページラベル、メタデータ、電子署名の保持は前提にできません。新しいPDFは署名済みの原本ではありません。暗号化PDFは対応範囲外で、パスワード解除サービスでもありません。OCR、墨消し、修復、PDF規格適合性の検証も行いません。

出力後の短い確認

  1. ページ数と見える順番をプレビューと照合します。
  2. 各元資料から数ページを選び、表示や欠落を確かめます。
  3. 元PDFとレシピを、閲覧用コピーとは別に保存します。
  4. 対話的機能や法的に重要な性質が必要なら、コピーで保持されたと考えず、適した専門手順を使います。

公開サイト資源を読み込んだ後、ページ処理はブラウザー内で行います。依存ライブラリーは同梱し、実行時CDNや文書アップロードは使いません。大きなPDFで使えるメモリーはブラウザーと端末に依存します。

編成後に文字編集やメモを加える場合は、KomoPDFで閲覧用コピーを編集・注釈する方法があります。コピーを使い、原本を保管してください。ページコピーやその後の注釈操作によって、原本の電子署名の有効性が確認されるわけではありません。
