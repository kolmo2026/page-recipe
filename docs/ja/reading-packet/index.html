必要なページを、短いレシピで

論文と補足資料から、再現できる閲覧用PDFを組み立てる

ページを並べ替えれば、今日読むための資料は作れます。その順序も保存すれば、後日同じ資料を再構成できます。この演習は合成したPDFを使うため、権利のない論文を再配布せずに結果を公開できます。

元ファイルを用意する

同梱の5ページのpaper.pdfと2ページのsupplement.pdfを取得します。各ページには元資料のラベルがあります。ローカルツールで両方を選択し、Aがpaper.pdf、Bがsupplement.pdfになっているか一覧で確認してください。ファイル選択の順番が異なる場合は、表示された別名をレシピに使います。

出力前に順序を確かめる

A:1-3,B:2,A:5

出力1 → Aの1ページ
出力2 → Aの2ページ
出力3 → Aの3ページ
出力4 → Bの2ページ
出力5 → Aの5ページ

「順序を確認」を押すと5ページ分が表示されます。これは1から数えるPDF内部の物理的な位置であり、紙面に印刷されたページ番号ではありません。A4とB1は意図的に省かれています。目的に合う省略か確認してから閲覧用コピーを作ってください。

二種類の成果物を保存する

  1. PDFを出力すると、別ファイルのpage-recipe-output.pdfがダウンロードされます。開いて元資料のラベルと順序を確認します。
  2. JSONレシピを保存します。含まれるのは指定、別名、元のファイル名、ページ数で、PDFの内容ではありません。
  3. 元ファイルも保管します。後日、同じ資料を選び直してJSONを読み込むと再構成できます。名前とページ数は照合しますが、意図した版の内容かは自分で確認します。

逆順と重複を試すならA:5-3,A:1,A:1を入力します。結果はA5、A4、A3、A1、A1です。重複を勝手に取り除かず、プレビューで明示します。

このツールはページのコピー用であり、全文書編集機能ではありません。続けて文字編集や注釈を行う場合は、同じ保守エコシステムの関連製品KomoPDFがあります。ページコピーでは文書単位の機能が失われる場合があります。フォーム、署名、しおりを含む資料では方法と制約も読んでください。
