論文、補足資料、必要な付録。それらを一つの閲覧用PDFにまとめ、組み立てた手順も残します。Page Recipeは短いページ指定を、ブラウザー内で新しいPDFに変換します。

サムネイル一覧も、アカウント登録も、クラウドへのアップロードもありません。元資料の別名、展開した順序、独立した出力ファイルを使います。
